Ili push notifications ziweze kufanya kazi, weka ONESIGNAL_REST_API_KEY kwenye Vercel Dashboard → Settings → Environment Variables → Production. Kisha redeploy.

  1. Ingia kwenye OneSignal Dashboard → App yako (Chidy Prime)
  2. Nenda kwenye Settings → Keys & IDs
  3. Copy REST API Key (sio App ID)
  4. Vercel → chidy-prime project → Settings → Environment Variables
  5. Ongeza ONESIGNAL_REST_API_KEY na paste value
  6. Redeploy
